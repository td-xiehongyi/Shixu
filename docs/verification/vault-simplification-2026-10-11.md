# 密码库编辑与提示精简验收（2026-10-11）

本轮按用户批准的精简方案实现，保留此前确定的进程内持续解锁行为。代码完成，自动化回归及最大化窗口下的真实 Windows 虚构库针对性验收通过；默认窗口视口点击问题、历史偶发主密码换密问题及正式准入仍未关闭。不称完整产品验收或正式密码库开放。

## 实现范围

- 编辑渠道、账号、描述时不再输入条目密码；更新请求省略密码，由密码引擎保留原 ProtectedValue。前端不会为编辑读取旧密码。
- “修改密码”按需展开新密码；取消会清空输入并保留原密码；显式空密码、null 均拒绝。创建条目仍要求密码，版本冲突检查不变。
- 移除“忘记主密码”入口及展开说明，只在创建库时保留“主密码无法找回，请妥善保管。”
- 复制与保存使用短提示，成功反馈约 2.5 秒消失；后续错误不会被先前计时器清除。保存失败不会误报为主密码输入错误。
- 删除重复底栏，数量合入“条目 · N”；保留删除确认、重试及当前虚构数据验收提示。
- 未改会话、生命周期、运行时接线及隔离视图控制文件；对应五个文件与本轮 baseline 哈希一致。保持切页、最小化、关闭到托盘和闲置不锁；手动锁定、完全退出/重启需重新解锁；显示密码 15 秒遮罩；不自动清理剪贴板；锁屏/睡眠仍在范围外。

## 真实桌面针对性验收

最终对照使用真实 Windows WebView2、固定 `--vault-fictional`、真实 IPC/隔离密码进程/KDBX/系统剪贴板，最大化原生窗口，正常鼠标操作，无模拟桥接、强制点击或 DOM 事件代替操作。`desktop-focused/desktop-result.json` 为 `complete=true`，脚本 exit 0，12 项通过：

1. 锁定页/创建页精简文案。
2. 无密码编辑账号和描述，原密码保持。
3. 主动隐藏密码。
4. 取消修改密码后保存，原密码保持。
5. 显式新密码必填，保存后显示新值。
6. 简短复制提示消失，剪贴板内容和解锁状态保留。
7. 切换模块保持解锁，已显示密码遮罩。
8. 最小化/恢复保持解锁。
9. 原生 WM_CLOSE 到托盘/原生恢复保持解锁。
10. 手动锁定隐藏详情、保留剪贴板，需重新解锁。
11. 终止测试拥有的进程并重启后为锁定态，解锁后修改内容和新密码均持久化。
12. 删除确认存在，仅删除本次唯一测试条目；再次解锁确认已删除。
