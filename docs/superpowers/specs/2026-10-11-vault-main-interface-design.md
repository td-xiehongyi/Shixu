## 界面与按钮

保留拾序左侧导航和浅色青绿色风格，密码库在右侧主内容区呈现。

解锁后：中间为条目列表，右侧为所选条目详情。搜索框右侧放“新增条目”；顶栏右侧为“修改主密码”“锁定”；详情右上为“编辑”；账号右侧为“复制账号”；密码右侧为“显示密码/隐藏密码”“复制密码”；描述完整保留换行；“删除条目”置于详情左下，和日常操作分开。没有描述时仍保留描述位置，显示“暂无描述”。

新增或编辑：复用现有四字段表单，在右侧详情区就地替换内容；沿用图一风格。保存/取消位于表单底部，不额外生成独立窗口。编辑保留当前完整密码输入要求，不擅自调整保存契约。删除沿用确认步骤，在详情区内呈现，不能误点即删。

锁定后：按图三在主内容区中央显示主密码输入、“解锁密码库”和次要的“新建密码库”。不保留列表、账号、描述或上一条详情。“新建密码库”沿用已有创建/存在库处理，不增加覆盖旧库功能。解锁失败就地提示，输入清理沿用现有实现。

选中条目、搜索过滤、空列表均需有明确状态；切换条目立即隐藏此前显示的密码。窄窗口按可用空间缩减列表宽度，必要时在密码库内容区滚动；账号/描述长文本换行，按钮不被挤出可操作区域。

## 原生接入与隔离

当前 App 通过 show_vault_window 打开独立 WebviewWindow；原生命令按实际调用 WebView 标签 main/vault 和本地 origin 校验。不能仅把 VaultWindow React 组件放进 main 并放宽密码权限。

推荐在同一原生主窗口内承载独立标签 vault 的子 WebView，主导航仍属于 main WebView；视觉表现是图一和图三。固定 Tauri 2.12.2 的 Window::add_child / WebviewBuilder 需要启用 unstable feature；不升级版本。此 API 的 Windows 运行效果尚未验证，不能把源码可用当成桌面验收通过。

- 由原生创建、定位、缩放和销毁密码视图；使用逻辑尺寸，保留当前导航宽度 214px，处理窗口缩放、DPI 和最大化。子视图不得遮挡导航。创建操作离开同步 WebView 回调执行。
- capabilities 从按窗口匹配改为按实际 WebView 匹配 main 与 vault，防止同窗口权限合并；原生 authorize 的双向隔离继续保留。main 只管理视图与非敏感状态，不能调用 vault_list/reveal/apply/unlock 等密码命令；vault 不能调用日历/QQ/设置命令。
- 仅加载打包的本地页面，保留 origin 校验和 CSP，不开放 iframe、远程页面或通用 JS 执行接口。
- 锁定事件定向发送到 vault WebView。导航底部仅接受原生发布的锁定/解锁状态，不传账号、描述、密码或会话。
- 密钥与完整解密库仍只存在隔离密码进程；界面仅接收原有摘要和按需单条密码。保持 KDBX Notes 的描述加密存储，保持既有字段兼容与长度限制。

## 生命周期与失败处理

会话规则：每次应用进程启动后首次访问密码库显示图三，成功输入主密码后保持可访问，直到用户手动锁定或完全退出应用。切换到日历、通知或设置、最小化、关窗到托盘均保持解锁；再次进入直接显示图一。取消此前的 5 分钟闲置自动锁定；仅单条密码明文显示仍在 15 秒后遮罩。完全退出或进程重启后必须重新输入主密码，不跨启动持久化解锁状态、主密码或密钥。

切离页面或关窗到托盘时，保留原生会话与密码子视图实例，隐藏该子视图，清除临时密码显示及密码输入；不把正常隐藏或 React 切页卸载当作锁库。未保存表单在切离时清理，不自动保存；切页期间正在保存的原生请求可完成，但不得重新显示已隐藏视图。重新进入恢复正常详情并重新核对会话状态，主密码无需再次输入。快速切换、双击入口和旧异步返回不得重复创建视图或覆盖更新后的手动锁定状态。

子视图创建、尺寸更新、锁定事件注册、密码进程或原生操作发生实际错误时仍撤销会话并显示明确错误；正常切页、闲置和到托盘不能被误报为故障。保留真正销毁密码视图时的会话撤销及内存清理。

保持用户此前取消的剪贴板自动清理与系统锁屏/睡眠钩子处于范围外。普通启动的正式存储准入保持当前阻断；先通过专用虚构密码库验收，不把 UI 集成等同于解除正式准入或发布阻断。
